HOW TO USE THE CONTAINER

   docker build -t llm-training-calculator:latest .

   # Run
   docker run --rm llm-training-calculator:latest

   # Save output to file
   docker run --rm llm-training-calculator:latest > results.txt

3. USING DOCKER COMPOSE:

   docker-compose up

================================================================================
HOW TO SHARE THIS CONTAINER
================================================================================

OPTION 1: Docker Hub (Best for wide distribution)
   
   docker tag llm-training-calculator:latest username/llm-calculator:latest
   docker login
   docker push username/llm-calculator:latest
   
   Recipients run:
   docker run --rm username/llm-calculator:latest

OPTION 2: Tarball File (Best for offline sharing)
   
   docker save llm-training-calculator:latest | gzip > llm-calculator.tar.gz
   
   Share the file (212MB), recipients load with:
   gunzip -c llm-calculator.tar.gz | docker load
   docker run --rm llm-training-calculator:latest

OPTION 3: Source Code Package (Best for developers)
   
   tar -czf llm-calculator-package.tar.gz \
     *.py Dockerfile docker-compose.yml run-docker.sh \
     .dockerignore README*.md DISTRIBUTION-GUIDE.md
   
   Recipients extract and run:
   tar -xzf llm-calculator-package.tar.gz
   cd llm-calculator-package
   ./run-docker.sh

OPTION 4: Git Repository (Best for collaboration)
   
   git init
   git add *.py Dockerfile docker-compose.yml run-docker.sh \
           .dockerignore README*.md DISTRIBUTION-GUIDE.md
   git commit -m "LLM Training Calculator"
   git remote add origin <your-repo-url>
   git push -u origin main
   
   Recipients clone and run:
   git clone <your-repo-url>
   cd <repo-name>
   ./run-docker.sh

CUSTOMIZATION FOR RECIPIENTS
